## Purpose

This directory contains standardized templates used throughout the customer journey.

Templates improve consistency, reduce repetitive work, and enable AI-assisted document generation.

---

## Available Templates

- Discovery Form
- Proposal
- Quotation
- Contract Outline
- Project Checklist
- Delivery Checklist
- Maintenance Plan
- Monthly Report
- Website Audit
- Case Study

---

## Principle

Templates should be:

- Reusable
- Easy to customize
- Client-friendly
- Continuously improved

Every completed project should improve at least one template.
