# Purpose

The Knowledge Base stores reusable business knowledge, technical standards, methodologies, and best practices.

Unlike documentation, this repository is continuously updated as the company gains experience.

Every AI agent should reference the Knowledge Base before making recommendations.

# Principles

Knowledge should be:

- Practical
- Reusable
- Up-to-date
- Actionable

Avoid theoretical explanations unless they improve business decisions.
