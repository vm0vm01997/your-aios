# Project Lifecycle

> Standard Project Flow of YouR 有頁｜企業數位成長顧問

---

# Purpose

This document defines the standard lifecycle of every client project.

Every AI agent follows this lifecycle unless otherwise approved by the CEO.

---

# Project Philosophy

Projects are not finished when a website is delivered.

Projects are complete only when the client achieves business growth.

---
